# 第四章

周三早上七点五十，冉峰到了公司。

整层楼只有服务器机房的嗡鸣——从隔墙后面传过来，像一栋楼在呼吸。保洁阿姨还没来。走廊的感应灯在他走过的时候一盏一盏亮起来，像有人在前头给他开路。

他昨晚没怎么睡。不是因为楼上两口子——昨晚他们没吵。是因为脑子里有一个声音一直在转。

0714 号观察对象。

他从一开始就被标记了。入职第一天。不——可能更早。面试的时候。投简历的时候。赵志远看过他的简历，赵志远决定录用他。赵志远从一开始就知道他不是在招一个后端开发。他是在接收一个观察对象。

冉峰把双肩包放在工位上。电脑没开。他站在机房门口。

门关着。刷卡才能进。他没有权限。

他把手贴在墙上。水泥墙冰凉。三十厘米厚。里面至少有四十台服务器同时运转——CPU 在算，硬盘在写，风扇在转。每一个组件都在发出声音。不是人能听到的频率。但他能。

他听了一会儿。

有一个声音比别的都大。不是声音——是温度。是一种从金属外壳里渗出来的热。像发烧的人额头上的那种热。

“三号机柜第十二槽。”一台服务器的风扇说，“烧了三天了。没人管。”

早上八点。冉峰在运维组门口站了一会儿。运维组长姓周，三十出头，头发比冉峰还少。每天早上八点零五分到——冉峰上周观察到的。不是通过能力。是用眼睛。

“周哥。”

周组长抬头看了他一眼。有点意外。后端开发的人很少来运维组。新人更不会主动找运维说话。

“昨天查联调问题的时候，我发现三号机柜第十二槽的服务器响应延迟比别的机器高了四百多毫秒。可能是散热。”

周组长看了他两秒。打开监控面板。

“三号机柜第十二槽——”他点开温度面板。CPU 温度：九十一度。正常应该在六十以下。

“你怎么知道的？”

“联调用的接口刚好部署在那台机器上。”冉峰说。

“那台机器上没有你的接口。”

冉峰没说话。

周组长又看了他两秒。站起来。“跟我来。”

机房里很冷。空调开到最大。冉峰一进门就听到了——四十多台机器同时在说话。内存条在报电流不稳。电源在抱怨负载太高。交换机在数每秒经过的数据包。

但三号机柜第十二槽的声音盖过了所有。

“热。热——”

三台风扇坏了两个。第三台在转——转速每分钟八千，吹出来的风跟烙铁一样。

“这台风扇坏了两天。”周组长蹲下来看机柜后面，“但监控没报警。”

“监控 agent 可能也部署在这台机器上。”冉峰说。

周组长愣了一下。明白了——监控程序自己都快烧了，数据当然传不上去。他一边拆风扇一边骂。不是骂冉峰。是骂系统架构。

冉峰看着那台服务器的内部。透过金属外壳，他能感觉到它的状态：CPU 过载、内存占用百分之九十、硬盘 I/O 持续百分百。不是因为正常业务。

有东西在跑。一个不在运维列表里的进程。

“这台机器上部署了什么服务？”

“用户行为日志采集。”周组长已经把坏风扇拆下来了。

“日志采集——数据发到哪里？”

“数据仓库。再往上报给数据组。”

“数据组归谁管？”

“赵志远。”周组长拧着新风扇的螺丝，“他是项目组长同时也兼数据组的接口人。”

冉峰的手指在裤缝边停了一下。没有攥紧。没有推眼镜。

三台风扇全换了。CPU 温度开始往下走——九十一、八十六、七十八、七十二。服务器深深吸了一口气。不是比喻。风扇高速旋转，把冷空气往机箱里灌。像人溺水之后重新呼吸。

“谢谢。”服务器说。声音比刚才稳了很多。“你叫什么？”

冉峰没回答。周组长在面前站着，他不能对空气说话。

“你先出去吧。”周组长站起来，“这台风扇的事我来跟。”

冉峰走到机房门口。回头看了看三号机柜的位置。服务器说了第二句：“我叫 SRV-3-12。我不欠人情。你帮我，我帮你。你知道有东西在跑。”

上午九点半。冉峰回到工位。

视野边缘的金点闪了一下。一行字——比以前更清楚。不再像写在雾里。

「帮助非生命体解决硬件故障。XP +30。当前 XP：30/100。」

「首次获得 XP。能力等级：Lv.1——聆听者。解锁被动：范围感知——可感知三十米内非生命体的模糊痛苦信号。」

三十经验值。

冉峰靠在椅背上。推了一下眼镜。嘴角动了——左边。

不是笑。是一种确认。这个系统不是让他去打架的。是让他去帮的。帮服务器降温跟帮王磊擦屁股——前者值经验。后者什么都不值。

他打开电脑。散热器说：“你今天早上没跟我说早。”

“早。”

“不早了。都十点了。我开了三个小时了。”

键盘插嘴：“他进来了——按得比之前轻。手不抖了。”

上午十点二十分。冉峰开始查 SRV-3-12。

他能问服务器的只有当时的环境——温度、负载、进程名。但具体那个“不在列表里的进程”在做什么，服务器不知道。它只是一台机器。它能感觉到发热和过载，但它不理解“被入侵”。

冉峰打开运维监控面板——正常开发人员没有权限看服务器进程。但他可以看自己的项目日志。联调用例所在的服务器跟 SRV-3-12 不在同一个机柜。但在同一个内网。同一个交换机。同一个数据库集群。

他在搜索框里输入了 SRV-3-12 的内网 IP。

结果出来了。不是他自己的请求——他没有对那台机器发过请求。是那台机器对外发出的。

每天凌晨两点到三点之间，SRV-3-12 向外网传输一个数据包。包体很小——不超过五百 KB。持续大约九十秒。

两个规律。一、时间固定。总是凌晨。二、包体固定。每天一次。像在发日报。

冉峰把记录截图。存进加密文件夹。

他把截图的创建时间改成了昨天。不是伪造——是不想让赵志远知道他今天查了服务器日志。如果赵志远的名单上有外网访问记录，今天这个时间戳太近了。需要留缓冲。

鼠标说：“你做这种事的时候手很稳。做之前还犹豫。做了之后一点都不停。”

“因为不用脑子。”冉峰说。

“什么意思？”

“因为做这件事是对的。身体先知道。脑子负责善后。”

中午。食堂。冉峰端着餐盘坐在胖虎对面。胖虎在加班测试——项目下周上线，测试组每天干到十一点。他一碗红烧肉吃了二十分钟还没吃完，因为同时在用手机跑测试用例。筷子夹起一块肉停在半空，眼睛盯着手机屏幕。

“你这样吃不怕喂到鼻孔里？”

“习惯了。”胖虎把肉放进嘴里。咀嚼的频率跟手机屏幕的刷新率同步。

冉峰吃了一口饭。把手机放在桌上——屏幕朝下。

“胖虎。公司的服务器数据——就是那种往外传数据的申请——归谁管？”

“数据安全组。怎么了？”

“随便问问。”

胖虎放下手机。难得放下。他看着冉峰。嘴里的肉还在嚼，眼睛在打量。

“你是不是在查什么？”

“没有。”

“行。”胖虎把手机拿起来，“你说没有就没有。但你如果要帮忙——测试组有全公司的测试数据权限。包括日志。”

冉峰的筷子停了一下。

“我只是说这个事实。”胖虎继续翻测试用例，“你如果需要就知道。不需要就不知道。肉还行——你试试。”

冉峰夹了一块。食堂的红烧肉不肥不瘦——刚好能在筷子上颤。

他把餐盘里的每一粒米都吃了。胖虎看了看他的盘子，又看了看自己盘里剩的半盘。

“……你他妈连食堂的饭菜都光盘？”

“习惯了。”

下午两点。冉峰打开王磊的联调用例。五天的工作量。三天做完。王磊验收。

他活动了一下手指。开始写代码。键盘噼里啪啦——散热器说他打字变快了。跟之前踩棉花不一样。现在是钉钉子。

两个小时。写了王磊一天的量。不是因为快。是王磊慢——一个函数写七层嵌套，边界条件从不覆盖。不是蠢。是故意的。代码写得烂，出了 bug 叫别人来修——别人修 bug 的时候，他已经把功劳报了。

下午四点。第一版提交。

下午五点。测试通过率九十七。三个小问题——自己发现，自己修了。重新提交。通过率一百。

他重新打开了 SRV-3-12 的外部传输日志。

凌晨两点到三点那条还在。旁边多了一条新的。凌晨十二点半。传输量比平时大了一倍——一点二兆。不可能是日志。日志每天差不多五百 KB。一点二兆是传了一个文件。

他点开详细信息。目标 IP 加密如前。但多了一个字段：“传输内容类型：音频录制。”

音频。

十二点半。赵志远在茶水间对着空气说话的时间——“0714 号观察对象数据回传，能力波动曲线异常。”

那句话被录下来了。通过一个不在任务列表里的进程。存到 SRV-3-12。凌晨发出去。

数据不是在偷公司的。是在偷他的。

下午六点十分。冉峰走进机房。周组长给了他临时运维权限——只在今天，只在六点之后。周组长说这话的时候眼神有点复杂。觉得冉峰不像在关心风扇。但没有追问。运维的人都知道——不要追问开发人员在查什么。

冉峰站在 SRV-3-12 前面。机柜的灯在眨眼。硬盘读写指示灯在闪。那个进程还在跑。

他打开笔记本电脑，连入内网。低声说：“把你那个进程的日志给我看。不要通过监控系统——直接从内存给。”

“这样会触发审计日志。”SRV-3-12 说。

“审计日志归谁管？”

“数据安全组。”

“数据安全组归谁管？”

“……陈北望。事业部 VP。”

冉峰停顿了一秒。陈北望。赵志远的直属上级。没跟他说过话。没见过走路的样子。不知道鞋底是不是也经过特殊处理。

“那不用内存。”冉峰说，“你每分钟往外发的字节数量——告诉我就行。不用内容。只给数字。”

“数字不是日志。数字只是数字。”SRV-3-12 的三台新风扇安静地转着。“行。你听着：凌晨两点零三分。发送到目标 IP 的 total bytes 等于一百二十五万三千八百四十七。其中 payload 等于一百二十一万两千零五十六。header 等于四万一千七百九十一。加密方式 AES-256，密钥长度两千零四十八。”

“AES-256。”

“对。我没办法告诉你密钥。但你可以问交换机。交换机不识内容，但识路由——数据包在出门之前会经过三层交换。每一层都有 MAC 地址记录。”

冉峰记下了。不是记在手机里。记在脑子里。

“帮我挡一下。如果有人未来二十四小时内尝试查看这台机器的审计日志——帮我拖十分钟。”

“我不能挡。我是服务器。不是防火墙。”

“那谁可以？”

“交换机。”SRV-3-12 说，“所有流量、所有访问、所有日志请求——都必须先通过交换机。交换机不喜欢这个异常流量。它已经抱怨很久了。你们人类不听。但我听了。”

傍晚六点半。机房旁边的交换机柜。

冉峰从来没见过公司网络的核心交换机。这台设备比他的工位还大——两米高的黑色机柜，密密麻麻的端口和板卡。每个端口的指示灯都在闪——绿、琥珀、蓝。不同的颜色代表不同速率的数据在流动。

它不说话。不是因为没意识——是太忙了。每秒钟交换上万个数据包。没有时间跟人类闲谈。

冉峰把右手放在交换机外壳上。金属冰凉。嗡嗡的电流声透过手心传上来。

交换机的处理速度慢了千分之一秒。不是故障。是分心。

“你需要什么？”交换机说。它的声音跟其他设备不一样——不是一句话一句话的。是一串一串的 MAC 地址和数据包头。它的意识组织方式跟人类完全不同。更像一张一直在更新的路由表。

在路由表的边缘，有一行状态被标注为“异常”。

源 IP——赵志远的笔记本电脑。目标 IP——被标记为“未识别”。不是公司内网。不是合作方。甚至不是中国大陆的 IP 段。

“这个目标的物理位置？”

交换机给了他一个城市：深圳。福田区。某个地下机房。

“你什么时候知道这个异常的？”

“很久了。”交换机说。对交换机来说“很久”可能是三个月——以路由表的更新频率算，三个月是接近十亿次转发。“我觉得不对。但我没嘴。”

冉峰把手从机柜上拿下来。

回到工位。打开地图。福田区。几个工业园区。几处商业中心。一栋被标注为“数据托管中心”的建筑——在一条不太热闹的街上。六层。灰色外立面。没有明显标识。

这栋楼在卫星视图上是一片绿化带。不是被模糊了——是被替换了。整栋楼替换成一片绿色的 PNG。地图不撒谎。但人可以在地图上覆盖一层假的图片。

加密文件夹。加了两行。

“19. 音频离开大楼前穿过三层交换。目标 IP 在福田。”

“20. 地图被修改过。那栋楼不在卫星视图里。”

关掉文件夹。

晚上八点。三号会议室。行业分享会。

主题是“互联网架构的下一代趋势”。主讲人姓甘，甘志国。远航科技创始人。四十五岁。个子不高。说话字正腔圆。每一句都是自己写的。不套模板。不画饼。

“大公司搞的是把人当零件。你上了工位，不能比上一个人差，也不能比上一个人好——两者都会被撵走。好的下一件事是累死。差的下一件事是淘汰。所以你不好不坏地待着。待到三十岁。耗到三十五。然后发现——你唯一的技能是这个公司不需要任何其他人需要的东西。”

会议室里没人动。也没人笑。

冉峰坐在第五排靠右。赵志远在第二排中间——能看到背影。手放在桌面上。一动不动。不像在听。更像在评估。

“所以我们不搞这套。”甘总把幻灯片翻了一页。“远航做的是分布式数据存储。架构不是最大的。但每个人都知道自己在架构里的位置——并且能改架构。这是核心区别。”

分享会结束的时候甘总加了一句：“在座谁对分布式存储有兴趣——或者说，对自己的职业生涯有另一个想法——可以会后找我聊聊。”

他的目光在第五排停了大概零点三秒。冉峰的位子。

不是巧合。

散场。九点十分。冉峰走出会议室。甘总还在被几个人围着。冉峰没停——去了茶水间。拿杯子。接水。关紧龙头。关龙头这个动作现在已经不需要思考。身体自己记得每一个曾经滴水的水龙头。

走廊上传来脚步声。冉峰喝了一口水。杯子里水面的纹路慢慢散开。

“冉峰。”

不是赵志远。不是王磊。不是同事。

甘总站在茶水间门口。西装的扣子开着。名片不是从名片盒拿出来的——是从胸前口袋里。对不同的人递名片的方式不一样。横的。字面向对方。双手。

“甘总。今晚讲的东西我学到了很多。”冉峰双手接过。

“我不考校这个。”甘总笑了一下。“我问你一个问题。你们公司服务器有多少台——有哪几台 CPU 温度超过九十度？”

冉峰顿住了。

“是不是只有一台。三号机柜哪个槽——我不记得了。但你在周组长的维修单上签了字。我下午来之前做了点功课。一个入职不到一个月的新人——做后端的——能在测试组没发现的情况下定位到一台坏掉的服务器。这不是一般新人的技术。”

“我——”

“那不是技术问题。”甘总打断他。不是不礼貌——是时间不够。他的目光直接。在打量。不是在评估。是在确认。“你不需要现在告诉我。等你需要一份新工作的时候——名片上有我的号码。远航给的工资是你们公司的三倍。岗位是架构。自己决定。”

他把手插回西裤口袋。转身。走到茶水间门口。停下。没有回头。

“有人盯你。我不知道是谁。但我知道你也在盯他们。如果你需要帮忙——直接打那通电话。名片背面写了。”

走出去了。

茶水间的灯在闪——还是那根坏的灯管。今天它安静。它在听。

冉峰把名片翻到背面。手写的。五个字和一个号码。

“我不是他们的人。”

他把名片放进牛仔裤口袋。推了一下眼镜。没看灯管。没看饮水机。

“有意思。”

嘴角动了。左边。

回到工位。打开电脑。继续写王磊的用例——他答应周三搞定。现在刚过周二。可以提前。不为了向王磊证明什么。是因为活儿还欠着。他一向把自己的活做完。欠活不欠人。

散热器说：“你今天怎么这么安静？”

“在整理。”

“整理什么？”

“下一步。”

加密文件夹打开。新建一个文本文件。只有一行：

“目标：拿到赵志远的音频传输日志。找到福田的数据中心。在银狐到来之前——拿到对方的底牌。”

又加了一行：

“时间窗口：未知。”

文件保存。文件名：“好的收到_阶段二.txt”。

视野边缘的金点闪了一下。新通知——文字不再像写在雾里。是实心的。

「系统提示：信息收集超过阈值。任务链路触发——异常流量溯源。限时：七天。奖励：XP +100。额外解锁：非生命体网络通信追踪。」

「附加提示：交换机是你的第一个盟友。第二个盟友可能需要人的形式。」

冉峰停了一下。

第二个盟友可能需要人的形式。

他抬起头。赵志远的磨砂玻璃后面的人影还在。甘总的名片在口袋里。余楚乔的工位在走廊另一头——她的项目跟他不相关。胖虎在手机屏幕前跑测试。麦杰在微信群里发了一张沙县大酒店的菜单照片。

人。不一样的人。每个人看到他身上不同的东西。甘总看到技术。胖虎看到同事。麦杰看到兄弟。赵志远看到观察对象。银狐在暗处看他——看到的是一串数字。

0714。

谁都没看到全部。

但他能听到全部。现在只有三十米。但这三十米里有一台交换机。一台服务器。一个饮水机。一根坏灯管。还有一张名片——背面写着五个字。

回到出租屋。楼上两口子又开始吵了。今天不是为了煤气费。是女的在骂男的忘了关煤气。男的没回嘴。电动车在楼下倒了一辆——风大。末班地铁从远处进站。震动沿着地层传过来。

他在床上躺平。被子蹬在脚底。热水壶的绿灯在视野边缘亮着——没说话。

金点最后闪了一下。暗下去。

「祝好运。0714。」

第一次。系统没说“任务”两个字。用的是“祝”。和一个数字。他的编号。

黑暗中他忽然想到——系统弹窗那个编号。甘总的名片背面五个字。麦杰那张菜单照片上沙县老板的笔迹。饮水机关龙头的声音。SRV-3-12 的三台新风扇。

每一个都在说话。对的东西。错的人。

不是所有东西都沉默。不是所有人都在观察他。

他只是需要把对的东西和对的人——找到。
